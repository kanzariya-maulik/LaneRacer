# Battle Tanks LAN — Arena Map Specifications

Battle Tanks features 3 distinct arena designs with strategic terrain combinations.

---

## Map 1: The Citadel ("Classic Fortress")

*Classic rectangular street grid with fortified central corridors, perimeter base positions, and tactical alleys.*

```
+-----------------------------------------------------------+
| [STEEL]                                           [STEEL] |
|              [BLUE EAGLE HQ - TEAM 2]                     |
|                                                           |
|    [BRICK]       [WATER MOAT]         [BRICK]             |
|                                                           |
|       [STEEL]    [CENTRAL CROSS]      [STEEL]             |
|                                                           |
|    [BRICK]       [WATER MOAT]         [BRICK]             |
|                                                           |
|              [RED EAGLE HQ - TEAM 1]                      |
| [STEEL]                                           [STEEL] |
+-----------------------------------------------------------+
```

### Tactical Highlights:
- Narrow alleys encourage precision sub-tile breaching.
- Water moats flank the central approach, creating long sniper channels between East and West wings.
- Corner forest clumps allow stealth flanking maneuvers around perimeter bases.

---

## Map 2: The Velocity Oval ("Stadium / Pill Arena")

*Geometry: Semicircle (left loop) + 2 parallel straights (top & bottom) + Semicircle (right loop) + Central island.*

```
       ======================= TOP STRAIGHT =======================
      /  [STEEL]   [BRICK]   [WATER MOAT]   [BRICK]   [STEEL]      \
    /     ====================================================      \
   |  [RED EAGLE]            [CENTRAL DIVIDER ISLAND]          [BLUE EAGLE] |
   |  (Team 1)               [BRICK CROSS-CORRIDOR]            (Team 2)     |
    \     ====================================================      /
      \  [STEEL]   [FOREST]  [ICE CHANNEL]  [FOREST]  [STEEL]      /
       ====================== BOTTOM STRAIGHT =====================
```

### Tactical Highlights:
1. **Top Straight ("Sniper Alley")**:
   - Flanked on the interior by a water moat. Tanks can fire across the moat into the central aisle to snipe enemy flankers.
2. **Bottom Straight ("Ambush Trench")**:
   - Dense forest canopy combined with an ice drag strip. Tanks gain high speed and momentum while sliding in camouflage.
3. **Dual Semicircle Loops**:
   - Provide rapid turnaround points connecting the top and bottom corridors.
4. **Central Island Cross-Cut**:
   - A central brick barricade that can be breached with shells or bombs to cut directly across the map.

---

## Map 3: The Orbital Ring ("Colosseum / Circular Arena")

*Geometry: Full Circle with Concentric Rings and 8 Radial Spoke Corridors.*

```
                           [NORTH EAGLE / TEAM 1]
                                 === 12:00 ===
                           /                      \
                 [OUTER RING - ICE TRACK]           \
               /                                      \
     [WEST EAGLE] === [MIDDLE RING - BRICK] === [EAST EAGLE]
       (09:00)   |                                |   (03:00)
                 |        [INNER CORE MOAT]       |
                 |      [CENTRAL POWERUP HUB]     |
                 |                                |
               \                                      /
                 \                                  /
                           \                      /
                                 === 06:00 ===
                           [SOUTH EAGLE / TEAM 2]
```

### Tactical Highlights:
1. **Outer Ring**:
   - Circular ice track around the perimeter enabling high-speed drift maneuvers and perimeter flanking.
2. **Middle Ring**:
   - Dense maze of destructible brick fortifications and steel bunkers.
3. **Inner Core**:
   - Fortified circular sanctum surrounded by a water moat, holding high-value powerups.
4. **8 Radial Spoke Corridors**:
   - Spoke gates (12:00, 1:30, 3:00, 4:30, 6:00, 7:30, 9:00, 10:30) can be breached to open omni-directional lines of fire.
5. **Multi-Team Scalability**:
   - 2 Teams: North (12:00) vs South (6:00).
   - 3 Teams: 12:00, 4:00, 8:00.
   - 4 Teams: 12:00, 3:00, 6:00, 9:00.
   - FFA: 8 perimeter gate spawns.
