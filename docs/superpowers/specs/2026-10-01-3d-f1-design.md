# LanRace 3D F1 — Design Spec

Date: 2026-10-01
Status: Approved in chat, pending written-spec review

## Goal

Turn LanRace (2D canvas LAN racer) into a 3D-rendered F1 game: real F1 circuits, 2023-season team liveries plus the Red Bull Suzuka special, chase camera. Stays a LAN browser game; lobby/chat/ready flow unchanged.

## Decisions

| Topic | Decision |
|---|---|
| 3D depth | Visual 3D only. Server physics stays 2D (`x, y, angle, speed`). Flat circuits, no elevation. |
| Circuits | Starter set from TUMFTM racetrack-database: Monza, Spa, Silverstone, Suzuka, Sakhir (Bahrain). Replace old Oval/Figure-8/Twisty. |
| Teams | 2023 grid (10) + "Red Bull — Suzuka Special" (2025 RB21 Honda RA272 tribute) as 11th livery. |
| Team cap | Max 2 players per livery (11 × 2 = 22 player cap; grid has 20 slots → 20 racers max, extra become spectators). |
| Livery method | One UV-unwrapped Blender car model + one painted texture per livery. No logos or sponsor text. |
| Three.js delivery | npm `three`, served by Express at `/vendor/three`, importmap. No build step, works offline. |

## Architecture

Server authoritative, 60 Hz tick, existing socket events kept. 3D is purely client rendering.

Coordinate mapping: server `(x, y)` → Three `(x, 0, y)`; `angle` → `rotation.y = -angle`. Car model faces +X.

## Tracks

Source: `https://raw.githubusercontent.com/TUMFTM/racetrack-database/master/tracks/<Name>.csv` (LGPL-3.0). Format: `# x_m,y_m,w_tr_right_m,w_tr_left_m`, ~5 m point spacing. Files: `Monza.csv`, `Spa.csv`, `Silverstone.csv`, `Suzuka.csv`, `Sakhir.csv`. Monaco not available.

Importer:
1. `SCALE = 6` game units per metre (tuning knob).
2. Constant width per track = median(`w_right + w_left`) × `WIDTH_MULT` (1.5, tuning knob) × `SCALE`.
3. Downsample to ~10 m spacing (every 2nd point).
4. Row 0 = start/finish; row order = driving direction.
5. Output `{id, name, path:[{x,y}], width}`; committed under `data/tracks/` so runtime never needs the internet.

`Track.js` derives:
- **Checkpoints:** 16 evenly spaced path points, `radius = width`. Must be hit in order (existing rule) — prevents Suzuka crossover shortcut.
- **Grid:** 20 slots, two staggered columns behind path[0], offset ±width/4 laterally, ~8 m apart along path. `startAngle` = heading of path[0]→path[1].
- **Ranking (server):** sort by `lap` desc, `checkpoint` desc, distance to next checkpoint asc; finished players by finish order. `rank` sent in `game_state`.

Physics cost: nearest-segment scan over ~700 segments × 20 cars × 60 Hz ≈ 840k checks/s. Acceptable; leave a `ponytail:` comment naming spatial index as the upgrade path.

### Car model

- Low-poly modern F1 car, ~3–5k tris, built in metres (~5.6 m long), facing +X, Y-up export.
- Parts: nose, front wing + endplates, chassis, sidepods, engine cover + shark fin, halo, helmet, floor, rear wing + endplates, 4 wheels.
- Body parts share one UV layout + `livery` material (texture swapped per team). Fixed materials: `carbon`, `tyre`, `rim`.
- Wheels as separate nodes `wheel_FL/FR/RL/RR` for spin.
- Client scale ×6 (matches `SCALE`).

### Team picker

- 11 cards: livery thumbnail, team name, `n/2` count; full cards greyed.
- Server emits `lobby_state_sync` on connect (before join) so counts are live.
- `join_lobby {username, teamId}` → server validates team exists and count < 2, else `join_error {reason}`; client re-enables picker.
- Team locked after join (refresh to change).
- Player chat/nametag colour = team `chatColor`.

## Renderer (`public/js/game3d.js`)

- ES module; reads globals `clientState`, `socket` from classic scripts.
- **World (built once per `game_init`):** grass ground plane (tiled pattern) + sky colour + fog; asphalt ribbon mesh from centreline (left/right offsets) with white edge lines; red/white kerbs on high-curvature sections (visual only); low red/white barrier at `width/2 + 80` (matches physics wall); chequered start/finish strip at path[0].
- **Cars:** load `car.glb` once, clone per player, apply cached livery texture; lerp position, shortest-arc lerp heading each frame; wheel spin ∝ speed; sprite name tag in `chatColor`.
- **Camera:** racer chase cam ~10 m behind, ~4 m up, smoothed, looks slightly ahead. Spectator: chase cam on race leader, Left/Right arrows cycle cars.
- **Lighting:** hemisphere + directional sun with shadows; shadow frustum follows camera; cars cast shadows.
- **HUD:** existing DOM HUD + 2D minimap canvas (track outline + coloured dots).
- **Speed units:** `kmh = speed / SCALE * 3.6`. Lobby speed setting in real km/h (default 240 ≈ current 400 u/s); server converts.
- Keyboard + touch joystick input kept; countdown and spectator overlays kept.

## Bug fixes in scope

1. Late joiners / spectators receive `game_init` (track + players) on join during a race.
2. Disconnected racer removed from `gameInstance.players` so the race can finish.
3. Chat rendered with `textContent` (fixes HTML injection via username/msg/colour).
4. Server type-checks all socket payloads (fixes crash on non-string `username`/`msg`).
5. `game_state` includes everything the client leaderboard needs (`rank`, `finished`); client uses server rank.

## Error handling

- `join_lobby`: username must be string; trim, cap 15 chars, empty → `Player<n>`. `teamId` must exist and be under cap.
- `chat_msg`: string, ≤100 chars.
- `update_settings`: whitelist fields; `trackId` ∈ known tracks; laps 1–50; speed 80–350 km/h.
- `input`: coerce each flag to boolean.
- Missing track JSON → server fails at startup with clear message.
- Client: `car.glb` / texture load failure → console error + coloured box fallback.

## Testing

`npm test` → `node --test` (stdlib, no new deps).

- `test/track.test.js`: each track closed loop; 16 checkpoints; 20 grid slots all on-track and non-overlapping (≥ 2 × car radius apart).
- `test/lobby.test.js`: team cap (3rd join same team rejected); sanitising of username/chat/settings/input.
- `test/game.test.js`: ranking order; disconnect removes racer and race can still finish.

Visual (manual, by Claude):
- Blender preview renders (side + top) per livery vs reference photos → shown to user before renderer work.
- Run server; two Chrome tabs via browser automation; join different teams; race a lap at Monza; screenshot chase cam, minimap, spectator view.

## Out of scope

Elevation, logos/sponsor text, in-lobby team switching, Cadillac, other players' steering animation, Monaco and the other ~20 dataset circuits.
